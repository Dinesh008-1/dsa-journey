# Kadane's Algorithm

- **Trigger:** Find the maximum sum of a contiguous subarray.
- **Core Insight:** A negative running sum hurts any future subarray, so reset it to `0`.
- **Approach:** Add each element to `sum`, update `max`, and reset `sum` if it becomes negative.
- **Time:** `O(n)`
- **Space:** `O(1)`

### Template
```java
int max = Integer.MIN_VALUE;
int sum = 0;

for (int num : nums) {
    sum += num;
    max = Math.max(max, sum);

    if (sum < 0) {
        sum = 0;
    }
}
return max;
```

### Common Mistakes
- Resetting `sum` before updating `max`.
- Initializing `max = 0` (fails for all-negative arrays).
- Forgetting that the subarray must be contiguous.
